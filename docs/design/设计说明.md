# 火眼审计助手 (fireeyeaud) — UI 设计说明

- 版本：v0.1.0
- 日期：2026-10-09
- 设计工具：pen.dev（画布源文件）
- 预览：`docs/design/preview/`（浅色）、`docs/design/preview-dark/`（深色）

---

## 1. 设计概述

一款纯本地、VS Code 风格的财务/会计审计助手。以「打开文件夹」工作区为入口，
左侧以窄活动栏 + 可展开资源管理器呈现项目文件，中间为 Agent 对话主区域，
右侧为可切换 tab 的成果栏，底部为状态栏。深浅双主题通过设计令牌实现。

设计原则：信息密度高、层级清晰、数据可追溯；以中性色承载大量数据，火橙色（accent）
作为唯一品牌强调色，风险等级用 danger/warning/info 三色区分。

## 5. 关键组件

- **活动栏项**：36×36 图标按钮；选中 `accent-weak` 底 + `accent` 图标。活动栏为可复用组件（7 项 + 底部主题/设置）。
- **作用域徽标**：小型 chip，标明配置项归属——「全局」(`info-weak` 底 / `info` 字) 或「本项目」(`accent-weak` 底 / `accent` 字)；用于 Models / MCP / Skills / 数据库连接 / 知识库各面板的列表项与新建表单（见设计文档 §14.20）。
- **配置卡片（三段式）**：左侧各配置面板（Models / MCP / Skills / SQL库 / 数据库连接 / 知识库）统一为三段式卡片——**头部**（图标 / 状态点 + 名称 + 类型 chip + `spacer` + 肩标区）、**主体**（元信息行）、**底部控制行**（`card__foot`）。肩标区 = 作用域徽标 ＋ **启用文字 chip**（`启用` `success` 底 / `停用` `text-3` 底；仅含启用字段的板块显示）。卡片底部常驻「修改 / 删除」，另保留与板块强相关的快捷按钮（SQL库「试跑」、数据库 / Models / 知识库「试连」）。
- **表单集中落盘**：启用开关、数据库表授权勾选、知识库远端库勾选等编辑控件移入右侧编辑表单，统一经 `FormActions` 保存；卡片不再内联保存。数据库 / Models / 知识库的「试连」在**新增态**走参数化接口（`POST /db/test`、`POST /models/test`、`POST /kb/test`，不落盘；给 `id` 时凭据缺省回退已保存值）。
- **搜索命中**：行内高亮块（`accent-weak` 底 + `accent` 字）拼在普通文本之间；按文件分组，行号等宽右对齐。
- **资源管理器树行**：25px 高，缩进 10/28/44，`chevron-down/right` 折叠态，文件类型着色。
- **疑点卡片**：等级色点 + 编号 + 金额（右）+ 描述 + 科目/状态 chip；选中 `accent-weak` 底 + `accent` 边框。
- **推理步骤行**：序号圆点（工具调用为 accent）+ 文本（工具调用用等宽字体）。
- **结果卡片**：`panel-bg` 底 + 边框，含结论文本与操作按钮（主/次）。
- **输入框**：`panel-bg` 底 + 边框，底部工具条（附件/选择工具/联网 + 发送）。
- **状态栏**：`activitybar` 底 + 顶部边框，左侧状态、右侧运行信息（等宽字体）。

## 6. 交互约定

- 活动栏点击任一项 → 左侧展开对应功能面板；再次点击或收起按钮 → 回退为纯图标条。
- 成果栏 tab 切换 疑点清单 / 证据图谱 / 底稿预览 / 证据日志，内容区复用右侧栏宽度。
- 疑点卡片选中与列表/图谱/详情联动（同一 `F-00xx` 标识贯穿）。
- 深浅主题可切换；所有颜色引用令牌，无硬编码主题色（`#FFFFFF` 等仅用于节点高光/纸张、开关旋钮）。

## 7. 活动栏功能（7 项）

点击图标，左侧展开对应功能面板（侧栏）。各项配置均支持**作用域**（全局 / 本项目，见设计文档 §14.20）：

1. **资源管理器**：工作区文件目录树（含 `.fireeye/`、数据文件、底稿），展开 / 折叠与新建。
2. **搜索**：工作区内关键词搜索（VS Code 式），见 §8。
3. **数据库连接**：配置只读数据库连接；连接后可在对话中选择数据源，并**限定 Agent 可访问的表与字段**（授权清单落盘 `.fireeye/`）。SQLite / Access 可由用户**上传数据库文件**——选择后自动复制到工作区「数据库」目录，路径写入连接。Access 连接首选 `sqlalchemy-access`(ODBC)；当系统缺少/无法使用 Access 驱动时，自动回退到纯 Python 解析(`access-parser` → 内存 SQLite)，无需 ODBC/JVM。
4. **知识库**：接入 Dify / RAGFlow（仅检索）——配置连接（base URL + API key）、测试连通、浏览远端知识库并勾选启用；Agent 经 `kb_search` 工具检索命中片段用于 RAG。见 §8.1。
5. **MCP**：管理 MCP Server（增删 / 启停 / 连接状态 / 工具列表 / 权限与沙箱范围）；真实连接（stdio/sse/http）、发现并调用工具（Phase 9）。
6. **Skills**：管理技能包（内置与自定义的提示词 + 工具组合，启停与参数）。
7. **Models**：管理模型配置（provider / base_url / api_key / model / 参数），多套配置并指定默认。

底部保留 **主题** 与 **设置**（全局选项，见 §7.1）。

### 7.1 设置页

设置页左侧导航：

1. **外观与语言**：主题（浅 / 深）、界面语言（`zh-CN` / `en-US`）。
2. **规则库**：用户自定义 SQL 规则（新增 / 编辑 / 启停 / 删除；`全局` 或 `本项目` 作用域，与 Models 等一致）；模型通过系统提示词感知并用 `run_rule` 运行。
3. **联网检索**：默认关闭，开启后可配 provider / key。
4. **数据与存储**：工作区数据目录、重建索引 / 数据库、清缓存。
5. **关于**：版本、许可、诊断与日志导出。

> 模型服务（provider / base_url / key / model）统一在活动栏 **Models** 面板管理；活动栏底部「主题」为外观快捷入口。

## 8. 搜索面板

VS Code 式，位于活动栏「搜索」，宽 330px：

- 搜索框：关键词输入 + 大小写 / 全词 / 正则 选项；可折叠的替换输入。
- 范围过滤：包含文件 glob（如 `*.xlsx, 底稿/**`）、排除 glob（如 `.fireeye/**, dist/**`）。
- 结果摘要：命中的文件数与结果条数。
- 结果树：按文件分组（文件类型图标 + 名称 + 命中数），组内列出命中行，行号等宽、关键词行内高亮。
- 右侧预览：打开命中文件，命中行整行高亮，顶部显示文件路径与命中导航。

---

## 8.1 知识库面板

位于活动栏「知识库」，**仅检索**（不建库 / 不上传），宽 330px：

- 顶部：**Provider 列表**（`kb_<n>`），每项为三段式卡片：头部（连接状态点 + 名称 + 类型徽标（Dify / RAGFlow）+ 作用域徽标）、主体（baseUrl；试连成功显示「已连接」）、底部控制行（试连 / 修改 / 删除）。
- 新增 / 编辑表单：类型（Dify / RAGFlow）、base URL、API key（经 `safeStorage` 加密，仅存引用）、作用域（全局 / 本项目）、默认参数（`topK` / `scoreThreshold` / 检索方式），并含「试连」（参数化，不落盘）与**远端知识库列表**（`GET .../knowledge`）：每行远端库名称 + `document_count`，勾选即启用（写入启用集，按作用域），经表单「保存」统一落盘。未配置 / 鉴权失败显示对应错误态。
- 底部说明：命中片段将作为证据写入证据链；若 `baseUrl` 非本机，提示「查询文本将发送至该地址」。
