# Phase 5.5 — 知识库接入（仅检索） Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. 建议按里程碑（K1→K2→K3→K4→K5）分批执行，每个里程碑结束运行一次验证并以一次提交收尾。

**Goal:** 在活动栏「知识库」面板配置 Dify / RAGFlow Provider（作用域 global/project），测试连通、浏览远端知识库并勾选启用；Agent 经 `kb_search` 工具 fan-out 检索命中片段，结果归一化并写入证据链。

**Architecture:** Provider 元数据用现有 scope 感知配置存储 `config.store(kind="knowledge")` → `knowledge.json`（global/project 合并，`_ID_PREFIX["knowledge"]="kb"`）；API Key 单独存于 `<global_dir>/config/kb_secrets.json`（不落项目库，safeStorage 推迟，见决策）。启用集存 `<scope config>/kb_enabled.json`。`kb/` 包提供 Provider 适配器（`dify` / `ragflow`），函数接受可注入的 `httpx.Client`（测试用 `MockTransport`），归一化为统一 `RetrievedChunk`。`tools/kb_search.py` 读有效启用集 fan-out，按 `score` 合并；证据由 Agent 循环既有的 `tool_call`/`tool_result` 记录机制承载。前端 `KnowledgePanel` 由占位改为真实面板。

**Tech Stack:** Python 3.12 · FastAPI · httpx · React 18 · Zustand

---

## 决策与偏差（执行前须知，2026-10-10 用户确认）

1. **凭据存储**：**同 Phase 5 DB 偏差**——API Key 明文写入 `<global_dir>/config/kb_secrets.json`（keyed by providerId），`knowledge.json` 只存 `apiKeyRef`；safeStorage 推迟 Phase 6（记为本期安全偏差）。
2. **适配器测试**：适配器函数接受可注入的 `httpx.Client`；单测用 `httpx.MockTransport` 验证请求体映射（`query`→Dify `query` / RAGFlow `question`、`topK`、`scoreThreshold`）与响应归一化。真实远端服务仅人工 E2E。
3. **仅检索**：不在应用内创建 / 上传 / 切分知识库。
4. **工具参数**：`kb_search({ query, kbIds?, topK?, scoreThreshold? })`；`kbIds` 匹配启用集的 `knowledgeId`；无 `kbIds` 时用有效启用集全量；`topK`/`scoreThreshold` 缺省取 Provider `defaults`，逐次可覆盖。
5. **证据**：复用 Agent 循环对每个 `tool_call`/`tool_result` 的证据记录（大结果由 `evidence.append_evidence` 的 16KB 阈值自动落 `artifactRef`）；本期不改证据层。
6. **HTTP 依赖**：`httpx` 由 dev 提升为运行时依赖。
7. **错误码**：新增 `E_KB_TYPE`（400）、`E_KB_CONN`（502），messageKey `error.kbType` / `error.kbConn`。

```python
"""Dify 知识库适配器（设计 §14.19）。

- 列表：`GET {baseUrl}/datasets`（Bearer）。
- 检索：`POST {baseUrl}/datasets/{id}/retrieve`。
- `query` 上限 250 字符，超长截断。
"""

from __future__ import annotations

from typing import Any

import httpx

_TIMEOUT = 30.0


def _get(client: httpx.Client | None) -> tuple[httpx.Client, bool]:
    if client is not None:
        return client, False
    return httpx.Client(timeout=_TIMEOUT), True


def list_knowledge(
    base_url: str, api_key: str, *, client: httpx.Client | None = None
) -> list[dict[str, Any]]:
    c, owned = _get(client)
    try:
        res = c.get(
            f"{base_url.rstrip('/')}/datasets",
            headers={"Authorization": f"Bearer {api_key}"},
            params={"page": 1, "limit": 100},
        )
        res.raise_for_status()
        data = res.json().get("data", [])
    finally:
        if owned:
            c.close()
    return [
        {"id": d.get("id"), "name": d.get("name"), "documentCount": d.get("document_count")}
        for d in data
    ]


def retrieve(
    base_url: str,
    api_key: str,
    knowledge_id: str,
    query: str,
    *,
    top_k: int = 5,
    score_threshold: float = 0.3,
    search_method: str = "hybrid_search",
    client: httpx.Client | None = None,
) -> list[dict[str, Any]]:
    payload = {
        "query": query[:250],
        "retrieval_model": {
            "search_method": search_method,
            "top_k": top_k,
            "score_threshold_enabled": True,
            "score_threshold": score_threshold,
        },
    }
    c, owned = _get(client)
    try:
        res = c.post(
            f"{base_url.rstrip('/')}/datasets/{knowledge_id}/retrieve",
            headers={"Authorization": f"Bearer {api_key}"},
            json=payload,
        )
        res.raise_for_status()
        records = res.json().get("records", [])
    finally:
        if owned:
            c.close()
    chunks: list[dict[str, Any]] = []
    for r in records:
        seg = r.get("segment") or {}
        doc = seg.get("document") or (r.get("document") or {})
        chunks.append(
            {
                "content": seg.get("content") or r.get("content") or "",
                "docId": r.get("document_id") or seg.get("document_id"),
                "docName": doc.get("name") or "",
                "score": r.get("score"),
            }
        )
    return chunks
```

**Step 4: 实现 `store/knowledge.py`**

```python
"""知识库 Provider 与启用集存储（设计 §14.19 / §14.20）。

- Provider 元数据：`config.store(kind="knowledge")` → `<scope>/knowledge.json`。
- API Key：`<global_dir>/config/kb_secrets.json`（keyed by providerId）。
- 启用集：`<scope config>/kb_enabled.json`（`{items:[...]}`）。
"""

from __future__ import annotations

import json
from pathlib import Path
from typing import Any

from ..config import store

KIND = "knowledge"
_TYPES = {"dify", "ragflow"}


def _secrets_path() -> Path:
    return store.global_config_dir() / "kb_secrets.json"


def _load_secrets() -> dict[str, str]:
    path = _secrets_path()
    if not path.exists():
        return {}
    try:
        data = json.loads(path.read_text("utf-8"))
        return data if isinstance(data, dict) else {}
    except (OSError, json.JSONDecodeError):
        return {}


def set_secret(provider_id: str, api_key: str | None) -> None:
    secrets = _load_secrets()
    if api_key:
        secrets[provider_id] = api_key
    else:
        secrets.pop(provider_id, None)
    path = _secrets_path()
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(json.dumps(secrets, ensure_ascii=False, indent=2), "utf-8")


def get_secret(provider_id: str) -> str | None:
    return _load_secrets().get(provider_id)


def list_providers(root: Path | None = None) -> list[dict[str, Any]]:
    return store.load_effective(KIND, root)


def get_provider(
    provider_id: str, scope: str, root: Path | None = None
) -> dict[str, Any] | None:
    return store.get_item(KIND, provider_id, scope, root)


def create_provider(
    data: dict[str, Any], *, api_key: str | None, root: Path | None = None
) -> dict[str, Any]:
    from ..errors import ApiError

    ptype = str(data.get("type") or "").lower()
    if ptype not in _TYPES:
        raise ApiError("E_KB_TYPE", 400, "error.kbType", {"type": ptype})
    payload = {k: v for k, v in data.items() if k != "apiKey"}
    payload["type"] = ptype
    item = store.create_item(KIND, payload, root)
    updated = store.update_item(
        KIND, item["id"], item["scope"], {"apiKeyRef": item["id"]}, root
    )
    if api_key:
        set_secret(item["id"], api_key)
    return updated


def update_provider(
    provider_id: str,
    scope: str,
    patch: dict[str, Any],
    *,
    api_key: str | None,
    root: Path | None = None,
) -> dict[str, Any]:
    if api_key:
        set_secret(provider_id, api_key)
    return store.update_item(KIND, provider_id, scope, patch, root)


def delete_provider(
    provider_id: str, scope: str, root: Path | None = None
) -> None:
    store.delete_item(KIND, provider_id, scope, root)
    set_secret(provider_id, None)


# ---- 启用集 ----


def _enabled_path(scope: str, root: Path | None) -> Path:
    from ..errors import ApiError

    if scope == "project":
        if root is None:
            raise ApiError("E_NO_WORKSPACE", 409, "error.noWorkspace")
        return store.project_config_dir(root) / "kb_enabled.json"
    return store.global_config_dir() / "kb_enabled.json"


def _read_enabled(path: Path) -> list[dict[str, Any]]:
    if not path.exists():
        return []
    try:
        data = json.loads(path.read_text("utf-8"))
    except (OSError, json.JSONDecodeError):
        return []
    items = data.get("items", []) if isinstance(data, dict) else []
    return items if isinstance(items, list) else []


def list_enabled(scope: str, root: Path | None = None) -> list[dict[str, Any]]:
    return _read_enabled(_enabled_path(scope, root))


def set_enabled(
    scope: str, items: list[dict[str, Any]], root: Path | None = None
) -> list[dict[str, Any]]:
    normalized = [
        {
            "providerId": i.get("providerId"),
            "knowledgeId": i.get("knowledgeId"),
            "name": i.get("name"),
            "scope": scope,
            "enabled": bool(i.get("enabled", True)),
        }
        for i in items
    ]
    path = _enabled_path(scope, root)
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(
        json.dumps({"items": normalized}, ensure_ascii=False, indent=2), "utf-8"
    )
    return normalized


def list_enabled_effective(root: Path | None = None) -> list[dict[str, Any]]:
    """global ⊕ project，键 (providerId, knowledgeId)；project 覆盖 global。"""
    merged: dict[tuple, dict[str, Any]] = {
        (e.get("providerId"), e.get("knowledgeId")): e
        for e in list_enabled("global", None)
    }
    if root is not None:
        for e in list_enabled("project", root):
            merged[(e.get("providerId"), e.get("knowledgeId"))] = {
                **e,
                "scope": "project",
            }
    return list(merged.values())
```

```python
"""kb_search：检索已启用的知识库并归一化命中片段（设计 §14.19 / §10.1）。"""

from __future__ import annotations

from pathlib import Path
from typing import Any

from ..errors import ApiError

DEFAULT_TOPK = 5
DEFAULT_THRESHOLD = 0.3


def kb_search(root: Path, params: dict[str, Any]) -> dict[str, Any]:
    from .. import kb
    from ..store import knowledge

    root = Path(root)
    query = str(params.get("query") or "")
    kb_ids = params.get("kbIds")

    enabled = [e for e in knowledge.list_enabled_effective(root) if e.get("enabled")]
    if kb_ids:
        wanted = {str(i) for i in kb_ids}
        enabled = [e for e in enabled if str(e.get("knowledgeId")) in wanted]

    providers = {p["id"]: p for p in knowledge.list_providers(root)}
    groups: dict[str, list[dict[str, Any]]] = {}
    for entry in enabled:
        groups.setdefault(str(entry.get("providerId")), []).append(entry)

    chunks: list[dict[str, Any]] = []
    for provider_id, entries in groups.items():
        provider = providers.get(provider_id)
        if provider is None:
            continue
        adapter = kb.adapter_for(provider["type"])
        key = knowledge.get_secret(provider_id) or ""
        defaults = provider.get("defaults") or {}
        top_k = int(params.get("topK") or defaults.get("topK") or DEFAULT_TOPK)
        threshold = params.get("scoreThreshold")
        if threshold is None:
            threshold = defaults.get("scoreThreshold", DEFAULT_THRESHOLD)
        for entry in entries:
            try:
                hits = adapter.retrieve(
                    provider["baseUrl"],
                    key,
                    str(entry.get("knowledgeId")),
                    query,
                    top_k=top_k,
                    score_threshold=threshold,
                    search_method=defaults.get("searchMethod", "hybrid_search"),
                )
            except Exception as exc:  # noqa: BLE001
                raise ApiError(
                    "E_KB_CONN", 502, "error.kbConn", {"reason": str(exc)}
                ) from exc
            for h in hits:
                chunks.append(
                    {
                        "provider": provider["type"],
                        "providerId": provider_id,
                        "knowledgeId": entry.get("knowledgeId"),
                        "knowledgeName": entry.get("name"),
                        "docId": h.get("docId"),
                        "docName": h.get("docName"),
                        "content": h.get("content"),
                        "score": h.get("score"),
                        "url": h.get("url"),
                        "metadata": h.get("metadata"),
                    }
                )

    chunks.sort(key=lambda c: c.get("score") or 0, reverse=True)
    limit = int(params.get("topK") or DEFAULT_TOPK)
    return {"chunks": chunks[:limit], "merged": len(groups) > 1}
```

## 风险与注意事项

- **明文 API Key**：`kb_secrets.json` 为明文（本机 `<global_dir>/config/`）；safeStorage 推迟 Phase 6——安全偏差，README 标注。
- **外部服务出网**：知识库为外部服务，命中片段写入证据链；非本机 base URL 会将查询文本发送至该地址（面板已有 `egress` 提示）。
- **适配器响应结构差异**：Dify `/datasets/{id}/retrieve` 的返回字段随版本有 `segment` 嵌套差异，归一化已做多路径兜底；真实版本需人工 E2E 校验。
- **无启用集 / 无命中**：`kb_search` 返回 `{"chunks": [], "merged": false}`，不抛错，交由 Agent 说明。
- **网络超时**：适配器默认 30s 超时；失败统一转 `E_KB_CONN`（502）。
- **kb_search fan-out**：多库串行检索；单库失败即整次失败（拒绝而非静默忽略）。
- **topK 语义**：逐库检索用 `top_k`、合并后再按 `topK` 截断；`merged` 表示命中来自多个 Provider。
